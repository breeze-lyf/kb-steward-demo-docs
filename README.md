# kb-steward-demo-docs

Example data only. This is the demo knowledge base that [KB Steward](https://github.com/breeze-lyf/kb-steward) keeps up to date.
Every change arrives as a pull request opened by `kb-curator` after the document owner approved it in chat; commits carry
`Approved-by`, `Requested-by`, `Impact` and `Retro-corrections` trailers. Nothing here is real company policy.
